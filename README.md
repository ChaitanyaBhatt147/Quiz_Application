# 🧠 Quiz Application

The **Quiz Application** is a Java-based interactive quiz system developed using **Java Swing and AWT**.  
The application allows users to answer multiple-choice questions and automatically calculates the final score based on their responses.

This project demonstrates **GUI development, event handling, and user interaction using Java**.

---

# 📚 About the Project

The Quiz Application is designed to simulate a simple quiz platform where users can test their knowledge by answering a set of questions.  
It provides a graphical interface for selecting answers and displays the result after the quiz is completed.

This project focuses on:

- Java GUI development using Swing
- Event handling in Java
- Interactive user interfaces
- Quiz logic and score calculation

---

# 🚀 Features

- Multiple-choice quiz questions
- Interactive graphical interface
